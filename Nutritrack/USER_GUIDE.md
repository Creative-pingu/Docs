## Quick Start

### Installing the App
1. On iPhone 16e, open Safari and navigate to: https://creative-pingu.github.io/NutriTrack/
2. Tap Share button -> Add to Home Screen
3. Launch from home screen (works offline after first online visit)

## Features

### Food Logging
1. Tap Log Food or + button
2. Search for food
3. Select food
4. Enter amount (grams)
5. Select meal type
6. Tap Log
**Tips**: Use recents list, standard serving presets available

### Daily Goals
- Set in Settings -> Daily Goals
- Progress rings show intake vs. goals
- Exercise refuel ratio adjusts goals based on activity

### Recipes
- Create: Recipes -> + -> Add ingredients -> Save
- Log: Log Food -> Recipes tab -> Select -> Enter servings
- Sync from Notion: Settings -> Sync from Notion -> Review -> Import

### Exercise Tracking
1. Tap Exercise in bottom navigation
2. Tap + to log new exercise
3. Select activity, enter duration
4. MET-based calorie estimates calculated automatically

### Data Export
1. Settings -> Export Data
2. ZIP bundle created with CSV (daily totals) + JSON (full log)
3. File downloads to Files app
4. "Last exported" timestamp saved

## Offline Usage
### What Works Offline
- Food, recipe, exercise, supplement logging
- View daily log and goals
- Food search (from cached database)
- All core tracking features

### What Requires Connectivity
- Notion sync
- Food database updates
- Data export (file download)

## Privacy & Security
- All data stored locally on your device
- No tracking or data collection
- Notion sync is read-only
- Open source code available on GitHub
